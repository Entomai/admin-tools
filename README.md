# Admin Tools

Admin Tools adds admin header shortcuts, structured header menus, and compact notifications for Botble CMS.

## Features

- Fast menu for common admin links.
- Header-left zone beside the Botble logo.
- Structured header menu hooks for plugin-owned menus.
- Structured notification hooks for consistent header notifications.
- Built-in Ecommerce, Contact, and Payment integrations when those plugins are active.
